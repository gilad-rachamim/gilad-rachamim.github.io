איך מדביקים את החתימה

בג׳ימייל במחשב
  1. לוחצים כאן "להעתיק חתימה לג׳ימייל".
  2. בג׳ימייל לוחצים על גלגל השיניים ⚙ למעלה ← "הצגת כל ההגדרות". או ישר: הגדרות ג׳ימייל.
  3. בלשונית "כללי" גוללים עד "חתימה" ← "+ יצירת חתימה חדשה" ← נותנים שם.
  4. לוחצים בתיבה הגדולה ומדביקים: Ctrl+V (במק: Cmd+V).
  5. מתחת לתיבה, ב"ברירות מחדל לחתימה", בוחרים את החתימה להודעות חדשות ולתשובות.
  6. גוללים לתחתית הדף ולוחצים "שמירת השינויים". זהו – החתימה תיכנס לבד בכל מייל.
באאוטלוק (במחשב ובאתר)
  1. לוחצים כאן "להעתיק עם הלוגו".
  2. אאוטלוק החדש או outlook.com: גלגל השיניים ⚙ ← "חשבונות" ← "חתימות" ← "+ חתימה חדשה".
  3. אאוטלוק הקלאסי: "קובץ" ← "אפשרויות" ← "דואר" ← "חתימות…" ← "חדש".
  4. מדביקים בתיבת העריכה (Ctrl+V), בוחרים את החתימה כברירת מחדל להודעות חדשות ולתשובות, ולוחצים "שמור" / "אישור".
בטלפון (ג׳ימייל, אאוטלוק, אייפון)
  1. אפליקציית ג׳ימייל: ☰ ← "הגדרות" ← בוחרים את החשבון ← "חתימה לנייד" ← מדביקים את "טקסט בלבד". האפליקציה מקבלת רק טקסט.
  2. אאוטלוק בטלפון: התמונה שלכם למעלה ← ⚙ ← "חתימה" ← מדביקים טקסט.
  3. אייפון (אפליקציית הדואר): פותחים את הדף הזה בספארי, "להעתיק עם הלוגו", ואז הגדרות ← אפליקציות ← דואר ← "חתימה" ← מדביקים. אם העיצוב השתנה – מנערים את הטלפון ובוחרים "בטל שינוי מאפיינים".

הפרטים נשמרים רק בדפדפן שלכם, כדי שתמצאו את החתימה כשתחזרו. שום דבר לא נשלח לשרת.

איך מוסיפים חתימה באאוטלוק – בכל הגרסאות

באאוטלוק יש כמה גרסאות, ובכל אחת החתימה נמצאת במקום אחר. מה שלא משתנה: את החתימה עצמה נוח יותר לבנות כאן, עם לוגו, קו צבעוני וכפתור ווטסאפ, ולהדביק אותה מוכנה. בניגוד לג׳ימייל, אאוטלוק במחשב שומר גם לוגו שבחרתם מקובץ, ולכן משתמשים בכפתור "להעתיק עם הלוגו".

Outlook החדש ו-outlook.com

לוחצים על גלגל השיניים ⚙ למעלה ← "חשבונות" ← "חתימות" ← "+ חתימה חדשה". נותנים שם, מדביקים בתיבה (Ctrl+V), ומתחת בוחרים את החתימה כברירת מחדל להודעות חדשות ולתשובות והעברות. לוחצים "שמור". זו החתימה האוטומטית – היא תיכנס לבד בכל מייל.

Outlook הקלאסי במחשב

"קובץ" ← "אפשרויות" ← "דואר" ← "חתימות…" (או ישר מחלון הודעה: "הוספה" ← "חתימה" ← "חתימות…"). לוחצים "חדש", נותנים שם ומדביקים בתיבת העריכה. בצד ימין למעלה, תחת "בחר חתימת ברירת מחדל", בוחרים אותה להודעות חדשות ולתשובות/העברות, ולוחצים "אישור". מי שמנהל כמה מחשבים יכול להוריד כאן "קובץ חתימה" ולשמור אותו בתיקיית החתימות של אאוטלוק.

שינוי חתימה וחתימה קבועה לתשובות

כדי לשנות חתימה נכנסים לאותו מקום, בוחרים את החתימה הקיימת, מוחקים ומדביקים את החדשה. חתימה קבועה גם לתשובות מגדירים בשדה "תשובות/העברות" – הרבה אנשים בוחרים שם חתימה קצרה יותר, למשל בתבנית "מינימלי", כדי שהשרשור לא יתארך.

חתימה באאוטלוק בטלפון

באפליקציית אאוטלוק: לוחצים על התמונה שלכם למעלה ← ⚙ הגדרות ← "חתימה". שם אפשר רק טקסט, אז לוחצים כאן "טקסט בלבד" ומדביקים. אם יש לכם כמה חשבונות, מסמנים "חתימה לכל חשבון" ומדביקים בכל אחד.

שאלות ותשובות

איך מוסיפים חתימה באאוטלוק?

ב-Outlook החדש: ⚙ ← חשבונות ← חתימות ← חתימה חדשה. בקלאסי: קובץ ← אפשרויות ← דואר ← חתימות ← חדש. מדביקים, בוחרים ברירת מחדל ושומרים.

איך עושים חתימה אוטומטית באאוטלוק?

אחרי שיוצרים את החתימה, בוחרים אותה כברירת מחדל להודעות חדשות ולתשובות/העברות. מאז היא נכנסת לבד.

איך משנים חתימה באאוטלוק?

נכנסים לחתימות, בוחרים את הקיימת, מוחקים את התוכן ומדביקים את החדשה, ושומרים.

הלוגו נשמר באאוטלוק?

כן. אאוטלוק במחשב שומר לוגו שהודבק עם החתימה. לוחצים "להעתיק עם הלוגו" ומדביקים.

איך מוסיפים חתימה באאוטלוק בטלפון?

באפליקציה: התמונה שלכם ← הגדרות ← חתימה. שם רק טקסט, אז מעתיקים "טקסט בלבד".

הכלי בחינם?

כן. בחינם, בלי הרשמה ובלי פרסומות, בטלפון ובמחשב.

עוד כלים בחינם שאולי יעזרו

חתימה במייל בטלפון ובאייפוןאיך מוסיפים חתימה למייל בטלפון: באייפון (אפליקציית דואר), באפליקציית ג׳ימייל באנדרואיד…דוגמאות לחתימה במייל – 20 חתימות לפי מקצועדוגמאות לחתימה במייל לפי מקצוע: עורך דין, רואת חשבון, סוכן נדל״ן, מורה, מטפלת, צלמת, קבלן…חתימה בג׳ימייל – יוצרים ומוסיפים בדקהאיך מוסיפים חתימה בג׳ימייל: יוצרים חתימה מעוצבת עם לוגו, טלפון וווטסאפ, מעתיקים בלחיצה…
