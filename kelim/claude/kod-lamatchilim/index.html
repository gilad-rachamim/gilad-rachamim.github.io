קלוד קוד למתחילים: מדריך התקנה צעד אחר צעד

עשרה שלבים מהמסוף הראשון ועד המשימה הראשונה. מעתיקים את הפקודה למערכת שלכם, מסמנים וי, וההתקדמות נשמרת. בחינם, בלי הרשמה ובלי פרסומות.

0 מתוך 10 שלבים · ההתקדמות נשמרת בדפדפן שלכם בלבד

Claude Code לא כלול בחשבון החינמי של claude.ai. צריך מנוי בתשלום (Pro, Max, Team או Enterprise), חשבון Console, או חיבור לספק ענן נתמך. בודקים באתר של Anthropic מה כולל התוכנית שלכם. הכלי הזה עצמו בחינם, אבל קלוד קוד עצמו דורש גישה.

ב-Windows: מקלידים PowerShell בתפריט התחל ופותחים. ב-Mac: Cmd+רווח ואז Terminal. ב-Linux: Ctrl+Alt+T. המסוף הוא חלון שבו מקלידים פקודות במקום ללחוץ על כפתורים.

בוחרים מערכת הפעלה למעלה, מעתיקים את הפקודה ומדביקים במסוף. ההתקנה לוקחת פחות מדקה. ב-Windows צריך גם Git for Windows מותקן.

מערכת: 

ב-Windows אפשר גם דרך WSL, ואז משתמשים בפקודת ה-Linux.

    
מקלידים claude --version ורואים מספר גרסה. אם מקבלים "לא מזוהה", סוגרים את המסוף, פותחים חדש ומנסים שוב. claude doctor בודק בעיות נפוצות.
claude --version

    
עם cd נכנסים לתיקייה שאתם רוצים לעבוד בה, מקלידים claude, ובפעם הראשונה נפתח דפדפן להתחברות לחשבון. מאשרים וחוזרים למסוף.
cd my-project
claude

    
הפקודה /init גורמת לקלוד לסרוק את התיקייה ולכתוב קובץ CLAUDE.md: תקציר של הפרויקט והכללים לעבודה בו. אפשר לערוך אותו אחר כך, או ליצור אחד מאפס במחולל CLAUDE.md.
/init

    
מתחילים קטן וברור: "תסביר לי מה עושה הפרויקט הזה", או "תוסיף כפתור הדפסה לדף הראשי". קלוד מציג מה הוא מתכוון לשנות, ומבקש אישור לפני שהוא כותב לקבצים.

    
לוחצים Shift+Tab עד שמופיע מצב תכנון. קלוד יכתוב תוכנית בלי לשנות קבצים, ואתם מאשרים או מתקנים לפני שהוא מתחיל. מצוין למשימות גדולות.

    
אפשר להשתמש בקלוד קוד גם דרך האתר של Claude ובאפליקציה בטלפון, ולהמשיך שיחה מהמחשב. בודקים באפליקציה אם האפשרות זמינה בתוכנית שלכם.

    
מורידים סקיל מהספריית הסקילים, שמים בתיקייה ~/.claude/skills ובודקים שקלוד מזהה אותו. כך מלמדים אותו לעשות דברים בדיוק כמו שאתם רוצים.

קלוד קוד למתחילים בעברית: ההסבר המלא

  
מה זה קלוד קוד, בשתי שורות

  
קלוד קוד הוא עוזר תכנות של Anthropic שרץ במסוף, בתוך תיקיית הפרויקט שלכם. הוא קורא קבצים, מריץ פקודות וכותב קוד לפי מה שביקשתם בעברית, ושואל אישור לפני כל שינוי. למדריך הזה אין צורך בידע קודם בתכנות: רק מחשב, חשבון מתאים ומשימה קטנה.

  
מה צריך לפני שמתחילים

  
שלושה דברים. מחשב עם Windows, Mac או Linux. חשבון של Claude בתוכנית שכוללת קלוד קוד, כי החשבון החינמי של claude.ai לא כולל אותו. ותיקייה עם פרויקט, או תיקייה ריקה לניסיון. ב-Windows מומלץ להתקין גם Git for Windows לפני ההתקנה. פקודות Git בעברית יעזרו לכם כשתגיעו לשמירת שינויים.

  
איך מתקינים בכל מערכת הפעלה

  
בשלב 3 במסלול למעלה בוחרים את המערכת שלכם ומקבלים פקודה אחת להעתקה. ב-Windows היא רצה ב-PowerShell, וב-Mac וב-Linux היא רצה במסוף. אין צורך להתקין Node.js: המתקין הנוכחי עובד בלעדיו. מי שמעדיף npm יכול להשתמש בהתקנה דרך npm מהתיעוד של Anthropic.

  
ההפעלה הראשונה

  
נכנסים לתיקיית הפרויקט עם cd, מקלידים claude, ובפעם הראשונה נפתח דפדפן להתחברות. אחרי האישור חוזרים למסוף ורואים תיבת כתיבה. מכאן מדברים עם קלוד כמו עם עובד חדש: כותבים מה רוצים, והוא מציע צעדים.

המשימה הראשונה: איך מנסחים

  
בקשה טובה אומרת מה רוצים, איפה, ומה נחשב סיום. במקום "תשפר את האתר", כתבו: "בקובץ index.html תוסיף כפתור שמדפיס את הדף, ותבדוק שהוא נראה טוב בטלפון". ככל שהבקשה מדויקת יותר, יש פחות סיבובי תיקון. אם אתם לא בטוחים, בקשו מקלוד קודם לשאול אתכם שאלות.

  
אישורים והרשאות: מה קלוד לא עושה לבד

  
כברירת מחדל קלוד שואל לפני שהוא כותב לקובץ או מריץ פקודה. אפשר לאשר פעם אחת, או לאשר סוג פעולה לכל השיחה. אל תאשרו מחיקות או פקודות שאינכם מבינים. אפשר להגדיר כללים בקובץ ההגדרות, ובינתיים קראו כל הצעה לפני שמאשרים.

  
מצב תכנון: לחשוב לפני שכותבים

  
ב-Shift+Tab עוברים בין מצבים. במצב תכנון קלוד קורא ומתכנן בלי לשנות כלום, ומציג תוכנית. זה הכי שימושי למשימה של יותר מכמה שורות: מתקנים את התוכנית בעברית, ורק אז מאשרים ביצוע.

  
CLAUDE.md: הזיכרון של הפרויקט

  
קלוד קוד קורא את הקובץ CLAUDE.md בתחילת כל שיחה בתיקייה. כותבים בו פקודות בנייה ובדיקה, כללי עבודה ומה אסור. אפשר ליצור אותו עם /init או במחולל CLAUDE.md וסקיל, שבונה אותו מתשובות לכמה שאלות ומאפשר להוריד.

  
סקילים: לימוד חד-פעמי שחוזר

  
סקיל הוא קובץ SKILL.md בתיקייה, שמלמד את קלוד משימה חוזרת: סיכום פגישה, בדיקת קוד, כתיבת הודעה. הוא נטען רק כשהוא רלוונטי, ולכן לא תופס מקום. 12 סקילים בעברית מוכנים להורדה, ואפשר לערוך כל אחד.

  
להמשיך מהטלפון

  
אפשר לפתוח שיחה של Claude Code גם מהאתר ומהאפליקציה, ולהמשיך אותה במחשב. כך אפשר לתת משימה בדרך ולמצוא אותה גמורה בבית. זמינות התכונה תלויה בתוכנית ובגרסה, ולכן בודקים באפליקציה.

שאלות ותשובות

  
כמה עולה קלוד קוד?
הכלי הזה בחינם. קלוד קוד עצמו דורש מנוי בתשלום או חיבור API, והמחירים משתנים, ולכן בודקים באתר של Anthropic.

  
אפשר להשתמש בקלוד קוד בחשבון החינמי?
לא. החשבון החינמי של claude.ai לא כולל קלוד קוד. צריך תוכנית שכוללת אותו, או חשבון Console.

  
צריך לדעת לתכנת?
לא כדי להתחיל. מתארים בעברית מה רוצים, וקלוד מציע ומבצע. עם הזמן כדאי ללמוד לקרוא קוד כדי לבדוק את התוצאה.

  
איך מתקינים ב-Windows?
פותחים PowerShell ומריצים את הפקודה שבשלב 3 במסלול. כדאי להתקין קודם Git for Windows.

  
מה זה מסוף?
חלון שבו מקלידים פקודות. ב-Windows זה PowerShell, ב-Mac זה Terminal.

  
מה עושה הפקודה /init?
סורקת את הפרויקט וכותבת קובץ CLAUDE.md עם תקציר והכללים. אפשר לערוך אותו.

  
קלוד קוד ישנה לי קבצים בלי לשאול?
כברירת מחדל הוא שואל אישור לפני כתיבה והרצת פקודות. אפשר לשנות הרשאות, אבל כדאי להתחיל בברירת המחדל.

  
אפשר להשתמש בו בטלפון?
אפשר להמשיך שיחות דרך האתר והאפליקציה, בהתאם לתוכנית. ההתקנה עצמה היא במחשב.

  
ההתקדמות שלי נשמרת?
כן, בדפדפן שלכם בלבד, בלי הרשמה. בדפדפן אחר או במצב פרטי היא לא תופיע.

  
המדריך הזה רשמי של Anthropic?
לא. זה אתר עצמאי, בחינם, שנבנה כמיזם חסד. את התיעוד המלא של Anthropic כדאי לקרוא ישירות.
