# מילון מונחים: עברית / רוסית / אנגלית (גל 1, 24.11.2026)

מקור הצורה הרוסית: שימוש בפועל באתרים רוסיים (נבדק 24.11.2026) ועקביות עם דפי הגיור החיים ברוסית.
כלל: אותו מונח – אותה כתיבה בכל האתר. ברוסית כותבים «моэль» (לא «моѓель»), «брит-мила» עם מקף (כמו בדפי הגיור). בכותרות חיפוש אפשר «брит мила» בלי מקף – גוגל מתייחס לשתיהן אותו דבר.
