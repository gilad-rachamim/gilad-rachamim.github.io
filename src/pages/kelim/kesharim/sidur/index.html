סידור אנשי קשר: איחוד כפולים ומספרים בצורה אחידה

מכניסים את אנשי הקשר, והכלי מוצא את מי ששמור פעמיים, מספרים בלי שם ומספרים שגויים, ומסדר את כל המספרים בצורה אחת. בסוף מורידים קובץ נקי.

1. מכניסים את אנשי הקשר
איך מוציאים את אנשי הקשר לקובץ?

מגוגל (מומלץ):

  1. נכנסים ל-contacts.google.com
  2. לוחצים על "ייצוא" (בתפריט בצד, או בשלוש הנקודות למעלה)
  3. בוחרים "Google CSV" ולוחצים "ייצוא"
  4. חוזרים לכאן ובוחרים את הקובץ שירד

מטלפון אנדרואיד: באפליקציית אנשי הקשר: תפריט ← ניהול אנשי קשר ← ייבוא או ייצוא ← ייצוא לקובץ VCF.

מאייפון: באתר icloud.com ← אנשי קשר ← בוחרים הכול ← ייצוא vCard.

2. מה מצאתי

תגית לכמה אנשים בבת אחת

מסמנים אנשים ברשימה (בלשונית "כולם" אפשר לחפש ולסמן את כל התוצאות), כותבים תגית, והיא נוספת בסוף השם. למשל "משה כהן" יהיה "משה כהן ישיבת שעלבים". מי שכבר יש לו את התגית לא יקבל אותה פעמיים.

3. מורידים קובץ מסודר
איך מחזירים את הקובץ? (חשוב לקרוא)

ייבוא מוסיף אנשי קשר ולא מחליף את הקיימים. כדי שלא יהיה לכם הכול פעמיים:

  1. פותחים את הקובץ החדש ובודקים שהוא תקין.
  2. בגוגל: contacts.google.com ← מסמנים את כולם ← מחיקה. מה שנמחק נשאר באשפה 30 יום, אפשר להחזיר.
  3. לוחצים "ייבוא" ובוחרים את הקובץ החדש.

טלפון שמסונכרן עם גוגל יתעדכן לבד. מיילים, ימי הולדת והערות שהיו בקובץ המקורי נשמרים.

שום איש קשר לא יוצא מהטלפון שלכם: הכול נעשה כאן בדפדפן, ונשמר רק במכשיר הזה כדי שלא תאבדו את העבודה באמצע.

לשלוח את הכלי לחבר

לנקות כפולים באנשי הקשר

מכניסים קובץ אנשי קשר מגוגל, מאנדרואיד או מאייפון, או מדביקים רשימה. הכלי מוצא מי ששמור פעמיים וממזג, מוצא מספרים בלי שם ומספרים שגויים, ומסדר את כל המספרים בצורה אחת.

תגיות וקובץ מסודר

אפשר להוסיף תגית לכמה אנשים בבת אחת, ולבטל כל פעולה. בסוף מורידים קובץ לגוגל (CSV) או לטלפון (VCF), עם מספרים בצורה מקומית או בינלאומית שעובדת גם בחו"ל.

בדף יש הסבר איך מוציאים את אנשי הקשר לקובץ ואיך מחזירים אותו. עוד: ימי הולדת ותאריכים.

איך מוציאים ומחזירים

באנדרואיד ובגוגל מייצאים את אנשי הקשר לקובץ, באייפון דרך iCloud. בדף יש הסבר צעד אחרי צעד. אחרי הסידור מורידים קובץ לגוגל (CSV) או לטלפון (VCF), ומייבאים. חשוב לקרוא את ההסבר לפני שמחזירים, כדי לא לקבל כפולים מחדש.

מה הכלי מתקן

מאחד אנשים ששמורים פעמיים, מסמן מספרים בלי שם ומספרים שגויים, ומסדר את כל המספרים בצורה אחת: 050-1234567, או בפורמט בינלאומי +972, שעובד גם בחו"ל. כל פעולה אפשר לבטל.

פרטיות

הקובץ נשאר במחשב או בטלפון שלכם. הסידור נעשה בדפדפן, ושום איש קשר לא נשלח לשרת. בסוף אפשר למחוק הכול מהמכשיר בכפתור אחד.

בחינם, ובלי הרשמה

אין כאן מנוי, אין גרסת פרימיום ואין פרסומות. הכלי בנוי כחסד, לכל מי שצריך אותו, ורץ בדפדפן שלכם. הדרך הכי טובה לעזור היא לשלוח את הקישור למי שזה יכול לחסוך לו זמן, או לספר לנו מה עוד חסר.

שאלות ותשובות

איך מוחקים אנשי קשר כפולים?

מכניסים את הקובץ, והכלי מציג את הכפולים למיזוג. בסוף מורידים קובץ מסודר.

איך מוציאים אנשי קשר מגוגל?

ב-contacts.google.com לוחצים "ייצוא", בוחרים Google CSV, וחוזרים לכאן עם הקובץ.

זה עובד עם אייפון?

כן. מייצאים vCard מ-icloud.com ומכניסים לכלי.

אפשר לבטל פעולה?

כן, יש כפתור לביטול הפעולה האחרונה.

איך מאחדים אנשי קשר שמורים פעמיים?

מכניסים את קובץ אנשי הקשר, הכלי מוצא את הכפולים ומאחד אותם, ואז מורידים קובץ מסודר ומייבאים לטלפון או לגוגל.
