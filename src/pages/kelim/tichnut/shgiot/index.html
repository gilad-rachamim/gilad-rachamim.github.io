מה להדביק

את כל ה-traceback, מהשורה הראשונה ועד האחרונה.

שש שגיאות שכל מתכנת Python פוגש, ומה הן אומרות

  • ModuleNotFoundError: No module named 'torch' – החבילה לא מותקנת בסביבה שמריצה את הקוד. לרוב התקנתם אותה ל-Python אחר. מתקינים עם python -m pip install torch, כך שההתקנה הולכת בדיוק לאותו Python שמריץ.
  • AttributeError: 'NoneType' object has no attribute ... – משתנה שציפיתם שיהיה בו ערך מכיל None. מלכודת קלאסית: a = a.sort(). הפונקציה ממיינת במקום ומחזירה None, ואז a נמחק.
  • IndexError: list index out of range – ביקשתם איבר שלא קיים. ברשימה של 5 איברים האינדקס האחרון הוא 4, ולא 5.
  • TypeError: can only concatenate str (not "int") to str – מחברים טקסט עם מספר. עוטפים את המספר ב-str(), או משתמשים ב-f-string.
  • RuntimeError: Expected all tensors to be on the same device – חלק מהנתונים על הכרטיס וחלק על המעבד. מעבירים הכול לאותו מקום עם .to(device), גם את המודל וגם את הקלט.
  • CUDA error: device-side assert triggered – משהו בתוך הכרטיס נכשל, ולרוב זו תווית מחוץ לטווח, למשל class 10 במודל עם 10 קטגוריות (0 עד 9).

טריק לשגיאות CUDA: להריץ שוב עם CUDA_LAUNCH_BLOCKING

הכרטיס עובד במקביל למעבד, ולכן שגיאת CUDA מופיעה לפעמים בשורה מאוחרת יותר מזו שגרמה לה. מריצים שוב עם CUDA_LAUNCH_BLOCKING=1 python train.py, ואז כל פעולה מחכה שהקודמת תסתיים, וה-traceback מצביע על השורה האמיתית. זה איטי, ולכן משתמשים בזה רק לאבחון.

טעויות בטיפול בשגיאות

לא כדאי לעטוף הכול ב-try ו-except: pass. השגיאה נעלמת, אבל הבאג נשאר, ומתגלה מאוחר יותר במקום אחר. גם torch.cuda.empty_cache() לא פותר חוסר זיכרון: הוא משחרר רק זיכרון שאף טנזור כבר לא משתמש בו. כדי לפנות באמת, מוחקים את המשתנים הגדולים עם del, או מקטינים את ה-batch.

המסביר בחינם, בלי הרשמה ובלי פרסומות. כדי לראות את הקוד רץ שורה אחרי שורה, ולהבין איפה ערך נהיה None, יש את המריץ צעד אחר צעד.

שאלות ותשובות

מה עושים עם CUDA out of memory?

מקטינים את ה-batch, טוענים את המודל בדיוק נמוך יותר (8 או 4 ביט), בודקים ב-nvidia-smi אם תהליך אחר תופס זיכרון, ובהרצה בלבד עוטפים ב-torch.no_grad().

הקוד שלי נשלח לשרת?

לא. הכול רץ בדפדפן מתוך מילון קבוע. שום דבר לא נשלח.

מה אם הכלי לא מכיר את השגיאה?

הוא אומר שלא זיהה אותה, ולא ממציא הסבר. אפשר לחפש את השורה האחרונה של השגיאה ברשת.

איך הוא מוצא את השורה הבעייתית?

הוא קורא את ה-Traceback ומחפש את השורה האחרונה שנמצאת בקוד שלכם, ולא בספרייה.

הדף הזה בחינם?

כן. הכול כאן בחינם, בלי הרשמה ובלי פרסומות.

למה כתוב No module named אף שהתקנתי את החבילה?

כמעט תמיד ההתקנה הלכה ל-Python אחר, למשל סביבה וירטואלית אחרת. מתקינים עם python -m pip install ושם החבילה, כדי שההתקנה תגיע לאותו Python שמריץ את הקוד.

מה זה device-side assert triggered?

שגיאה שקרתה בתוך הכרטיס. ברוב המקרים זו תווית מחוץ לטווח בפונקציית ההפסד. מריצים שוב עם CUDA_LAUNCH_BLOCKING=1 כדי לראות את השורה המדויקת.

למה empty_cache לא מפנה זיכרון?

כי torch.cuda.empty_cache() משחרר רק זיכרון שאף טנזור כבר לא מחזיק. טנזורים שעדיין קיימים במשתנים ממשיכים לתפוס מקום, ולכן מוחקים אותם עם del או מקטינים את ה-batch.
