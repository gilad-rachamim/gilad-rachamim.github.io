הסדר שבו SQL באמת רץ

כותבים SELECT בהתחלה, אבל המסד מבצע את השאילתה בסדר אחר: FROM ו-JOIN, אחר כך WHERE, GROUP BY, HAVING, ורק אז SELECT ו-ORDER BY. בגלל זה אי אפשר להשתמש ב-WHERE על תוצאה של COUNT, ובשביל זה יש HAVING. מי שמבין את הסדר הזה פותר חצי משאלות הראיון.

מה שואלים בראיון

שאלות נפוצות: הסטודנט עם הממוצע הכי גבוה בכל קורס, קורסים בלי אף נרשם (LEFT JOIN עם IS NULL), הציון השני הכי גבוה, ומי נרשם ליותר משלושה קורסים (GROUP BY עם HAVING). כל אלה מופיעים בתרגילים כאן. להכנה מלאה יש הכנה לראיון טכני וסימולטור ראיון.

מה ההבדל בין WHERE ל-HAVING?

WHERE מסנן שורות לפני הקיבוץ, ו-HAVING מסנן קבוצות אחרי GROUP BY, למשל לפי COUNT או AVG.

מה ההבדל בין INNER JOIN ל-LEFT JOIN?

INNER JOIN מחזיר רק שורות שיש להן התאמה בשתי הטבלאות. LEFT JOIN מחזיר את כל השורות מהטבלה השמאלית, גם בלי התאמה.
