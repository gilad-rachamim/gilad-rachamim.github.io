פקודות Git בעברית: מה לעשות עכשיו?

שכחתם קובץ, נתקעתם בקונפליקט, או עשיתם commit לענף הלא נכון? בוחרים את המצב, ומקבלים את הפקודות עם הסבר – ואזהרה כשמשהו לא הפיך.

    
      
    
      
    
        
         לשלוח לעצמי
      
    
      
    מה כל חלק עושה
    
      
      
    
      
  
      
  
      הכלל הכי חשוב: מה שכבר עשיתם לו push – לא משכתבים (amend, reset), אלא מתקנים בשמירה חדשה (revert). ו-git reflog מציל כמעט הכול.
      
  
       לשלוח לחבר מהלימודים
      

      


      
  
      פקודות Git בעברית, לפי מה שקרה לכם
      
  
      רוב מי שמתחיל עם Git לא צריך עוד מדריך ארוך. הוא צריך לדעת מה להקליד עכשיו: שכחתי קובץ ב-commit, נתקעתי בקונפליקט, עשיתי commit לענף הלא נכון. בוחרים את המצב, ומקבלים את הפקודות המדויקות עם הסבר בעברית לכל אחת.
      
  
      אזהרה לפני מה שלא הפיך
      
  
      פקודות כמו reset או push בכוח יכולות למחוק עבודה. ליד כל פקודה כזו מופיעה אזהרה. הכלל החשוב: מה שכבר עלה ב-push לא משכתבים, אלא מתקנים ב-commit חדש (revert). ו-git reflog מציל כמעט הכול.
      
  
      לסטודנטים, למשרה ראשונה ולמי שלומד לבד. בחינם ובלי הרשמה. עוד למתכנתים: הכנה לראיון טכני ראשון ומסביר שגיאות בעברית.
      
  
      מצבים נפוצים
      
  
      למשל: שכחתי קובץ ב-commit האחרון, עשיתי commit לענף הלא נכון, נתקעתי בקונפליקט במיזוג, או רוצה לבטל שינויים בקובץ ולחזור לגרסה השמורה. מקלידים בחיפוש מילה כמו "קונפליקט" או "ענף", ומגיעים ישר למצב. כפתור "להעתיק" מעתיק את הפקודות.
      
  
      שלוש פקודות שכדאי להכיר
      
  
      git status מראה מה השתנה ומה מוכן ל-commit. git log --oneline מראה את ההיסטוריה בקצרה. ו-git reflog מראה כל מקום ש-HEAD היה בו, ולכן אפשר לחזור גם אחרי reset שנראה כמו טעות.
      
  
      מה הפיך ומה לא
      
  
      כל עוד לא עשיתם push, כמעט הכול הפיך, גם reset. אחרי push, שינוי ההיסטוריה משפיע על כל מי שעובד איתכם, ולכן עדיף revert. ולפני פקודה מסוכנת אפשר תמיד ליצור ענף גיבוי: git branch backup.
      
  
      למה זה בחינם
      
  
      הכלים של גילעד רחמים נבנים כחסד: בלי תשלום, בלי פרסומות ובלי הרשמה, כדי שכל אחד יוכל להשתמש בהם. מי שרוצה לעזור, שולח את הדף לחבר שזה יכול לעזור לו. חסר לכם כלי? אפשר לבקש כלי חדש.
      

      

      
  
      שאלות ותשובות
      
  
      איך מבטלים commit אחרון ב-Git?
      תלוי אם כבר עשיתם push. אם לא, אפשר לחזור אחורה עם reset. אם כן, עדיף revert, שיוצר commit חדש שמבטל את הקודם. בכלי בוחרים את המצב ומקבלים את הפקודה המתאימה.
      
  
      מה עושים בקונפליקט במיזוג?
      פותחים את הקבצים המסומנים, בוחרים מה נשאר בין הסימנים, שומרים, ואז add ו-commit. בכלי יש את הפקודות לפי הסדר, עם הסבר.
      
  
      איך מוסיפים קובץ ששכחתי ל-commit האחרון?
      add לקובץ ואז commit עם amend, כל עוד לא עשיתם push. אחרי push עדיף commit חדש.
      
  
      הכלי מתאים למתחילים?
      כן. כל פקודה מוסברת בעברית פשוטה, ויש אזהרה ליד מה שמשנה היסטוריה או מוחק.
      
  
      איך מבטלים את ה-commit האחרון?
      אם עוד לא עשיתם push: git reset --soft HEAD~1 מבטל את ה-commit ומשאיר את השינויים. אם כבר עשיתם push: git revert יוצר commit חדש שמבטל אותו.
