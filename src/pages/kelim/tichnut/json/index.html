מסדר JSON: סידור, כיווץ ובדיקת שגיאות

מדביקים, לוחצים, ומקבלים JSON מסודר. וכשמשהו שבור – רואים בדיוק איפה ולמה.


  
ה-JSON לא יוצא מהדפדפן שלכם ולא נשמר בשום מקום, כך שאפשר להדביק גם נתונים פנימיים. בכל זאת, מפתחות API וסיסמאות עדיף לא להדביק בשום אתר.

  
 לשלוח את הכלי לחבר






  
סידור JSON ומציאת שגיאות, בדפדפן

  
JSON הוא הפורמט שבו תוכנות ואתרים מעבירים נתונים. כשהוא מגיע בשורה אחת ארוכה, אי אפשר לקרוא אותו. מדביקים כאן, לוחצים "לסדר", ומקבלים אותו מסודר, עם הזחה ברורה.

  
מוצא בדיוק איפה השגיאה

  
פסיק מיותר, מרכאות חסרות או סוגריים שלא נסגרו? הכלי מראה באיזו שורה ובאיזה עמודה השגיאה, ולמה. ככה מתקנים בשנייה במקום לחפש בעיניים.

  
לסדר, לכווץ ולמיין

  
בוחרים הזחה של 2 רווחים, 4 רווחים או טאב, או מכווצים הכול לשורה אחת. אפשר גם למיין את המפתחות לפי א-ב, נוח כשמשווים שני קבצים.

  
לא יוצא מהמחשב

  
ה-JSON לא נשלח לשום שרת ולא נשמר, ולכן אפשר להדביק גם נתונים פנימיים. ובכל זאת, מפתחות API וסיסמאות עדיף לא להדביק בשום אתר. עוד: בודק Regex.

  
לקידוד ולפענוח: ממיר Base64 שתומך בעברית, עם קידוד URL ופענוח JWT.

  
שגיאות נפוצות ב-JSON

  
פסיק אחרי האיבר האחרון, מרכאות בודדות במקום כפולות, מפתח בלי מרכאות, והערות בתוך הקובץ. כל אלה מותרים ב-JavaScript, אבל לא ב-JSON, ולכן קובץ שנראה תקין נכשל. הכלי מסמן את השורה ואת העמודה של הבעיה.

  
פרטיות

  
ה-JSON לא יוצא מהמחשב. הסידור והבדיקה רצים בדפדפן שלכם, ולכן אפשר להדביק גם קובץ הגדרות או תשובה מ-API עם מידע פנימי. גם כשהקובץ גדול, הסידור לוקח שנייה.

  
בחינם, ובלי הרשמה

  
אין כאן מנוי, אין גרסת פרימיום ואין פרסומות. הכלי בנוי כחסד, לכל מי שצריך אותו, ורץ בדפדפן שלכם. הדרך הכי טובה לעזור היא לשלוח את הקישור למי שזה יכול לחסוך לו זמן, או לספר לנו מה עוד חסר.

  
השגיאות הנפוצות ב-JSON

  
פסיק אחרי האיבר האחרון ברשימה או באובייקט, מרכאות בודדות (') במקום כפולות ("), מפתח בלי מרכאות, הערות (// או /* */) שלא מותרות ב-JSON, וסוגריים שלא נסגרו. הכלי מסמן את השורה והעמודה של השגיאה ומסביר אותה בעברית, כך שלא צריך לחפש בעין בקובץ של אלף שורות.

  
מתי לסדר ומתי לכווץ

  
JSON מסודר עם הזחות נוח לקריאה ולבדיקה. JSON מכווץ לשורה אחת חוסך מקום בשליחה ובשמירה. מיון מפתחות עוזר להשוות בין שתי גרסאות של אותו קובץ. ולטוקנים ולקידוד יש ממיר Base64 ופענוח JWT.





  
שאלות ותשובות

  
איך מסדרים JSON?
מדביקים את ה-JSON, בוחרים הזחה ולוחצים "לסדר". מקבלים אותו מסודר ומעתיקים בלחיצה.

  
איך מוצאים שגיאה ב-JSON?
מדביקים ולוחצים "לסדר". אם יש שגיאה, הכלי מראה את השורה, העמודה והסיבה.

  
אפשר לכווץ JSON לשורה אחת?
כן. כפתור "לכווץ לשורה אחת" מוריד את כל הרווחים.

  
הנתונים נשלחים לשרת?
לא. הכול רץ בדפדפן, ושום דבר לא נשמר.

  
למה JSON לא מקבל פסיק בסוף?
כי התקן של JSON מחמיר יותר מ-JavaScript: אין פסיק אחרי האיבר האחרון, אין הערות, ומרכאות רק כפולות.

  
למה JSON לא מאפשר פסיק בסוף?
התקן של JSON לא מתיר פסיק אחרי האיבר האחרון. JavaScript מקבל אותו, אבל JSON תקני לא.

  
אפשר לכתוב הערות בקובץ JSON?
לא בתקן הרגיל. הערות יגרמו לשגיאה, והכלי יראה איפה היא נמצאת.
