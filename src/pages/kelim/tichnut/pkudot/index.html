מחולל פקודות GPU בעברית: nvidia-smi, Docker, PyTorch ו-nvcc

בוחרים מה רוצים לעשות עם כרטיס ה-NVIDIA, ומקבלים את הפקודה המדויקת – עם הסבר בעברית על כל חלק, כדי להבין ולא רק להעתיק.

    
      
    
      
    
        
         לשלוח לעצמי
      
    
      
    מה כל חלק עושה
    
      
      
    
      
  
      
  
      הפקודות נבדקו מול התיעוד של NVIDIA, Docker ו-PyTorch, אבל גרסאות משתנות – אם משהו לא עובד, כדאי להדביק את השגיאה במסביר השגיאות. פקודות עם ⚠️ משנות משהו במחשב: לקרוא לפני שמריצים.
      
  
       לשלוח את הכלי לחבר
      

      


      
  
      פקודות לכרטיס NVIDIA, עם הסבר לכל חלק
      
  
      רוצים לראות מי תופס את הזיכרון בכרטיס, להריץ Docker עם GPU, להתקין PyTorch שרואה את CUDA, או לקמפל ולמדוד קרנל? בוחרים מה רוצים לעשות, ממלאים כמה פרטים, ומקבלים פקודה מוכנה ל-Linux או ל-Windows.
      
  
      להבין, לא רק להעתיק
      
  
      כל חלק בפקודה מוסבר בעברית: מה הדגל עושה ולמה הוא שם. פקודות שמשנות משהו במחשב, כמו הגבלת הספק או סגירת תהליך, מסומנות באזהרה כדי לקרוא לפני שמריצים.
      
  
      הפקודות נבדקו מול התיעוד של NVIDIA, Docker ו-PyTorch, אבל גרסאות משתנות. אם משהו נכשל, מדביקים את השגיאה במסביר השגיאות. ולבדוק כמה זיכרון צריך: מחשבון VRAM.
      
  
      לאיזו מערכת
      
  
      בוחרים Linux, WSL, Mac או Windows (PowerShell), והפקודה יוצאת בתחביר הנכון למערכת שלכם. אפשר לחפש לפי מה שרוצים לעשות, למשל "זיכרון" או "docker", ו"להעתיק" מעתיק את הפקודה כמו שהיא.
      
  
      פקודות שכדאי להכיר
      
  
      nvidia-smi מראה את הכרטיס, את הזיכרון התפוס ואת התהליכים שרצים עליו. ב-PyTorch, torch.cuda.is_available() בודק אם הספרייה רואה את הכרטיס. ו-nvcc --version מראה איזו גרסה של CUDA מותקנת לקומפילציה.
      
  
      כשמשהו נכשל
      
  
      רוב הבעיות הן חוסר התאמה בין הדרייבר, גרסת CUDA וגרסת PyTorch. אם פקודה נכשלה, מדביקים את השגיאה במסביר השגיאות באתר, ומקבלים הסבר בעברית מה לבדוק. הפקודות מתאימות גם למחשב בבית וגם לשרת בענן, ומסומנות באזהרה כשהן משנות משהו.
      
  
      בחינם, ובלי הרשמה
      
  
      אין כאן מנוי, אין גרסת פרימיום ואין פרסומות. הכלי בנוי כחסד, לכל מי שצריך אותו, ורץ בדפדפן שלכם. הדרך הכי טובה לעזור היא לשלוח את הקישור למי שזה יכול לחסוך לו זמן, או לספר לנו מה עוד חסר.
      

      

      
  
      שאלות ותשובות
      
  
      איך רואים מה רץ על כרטיס המסך?
      בפקודה nvidia-smi, שמגיעה עם הדרייבר של NVIDIA. היא מציגה טמפרטורה, הספק, זיכרון בשימוש ואת התהליכים שרצים. בכלי אפשר גם לקבל אותה בעדכון כל כמה שניות.
      
  
      איך מריצים Docker עם GPU?
      צריך את NVIDIA Container Toolkit ואת הדגל --gpus. בכלי בוחרים "Docker עם GPU" ומקבלים את הפקודה המלאה עם הסבר.
      
  
      יש פקודות גם ל-Windows?
      כן. בוחרים למעלה Linux או Windows (PowerShell), והפקודות מתאימות את עצמן. חלק מהפעולות זמינות רק ב-Linux, וזה כתוב ליד.
      
  
      הכלי מריץ משהו במחשב שלי?
      לא. הוא רק בונה את הפקודה. אתם מעתיקים ומריצים בעצמכם.
      
  
      איך בודקים ש-PyTorch רואה את הכרטיס?
      מריצים ב-Python: import torch; print(torch.cuda.is_available()). אם יוצא True, הכרטיס זמין. אם False, בודקים את הדרייבר ואת גרסת PyTorch שהותקנה.
