    גלגל שמות לכיתה, לקבוצה ולמשפחה

    גלגל שמות בוחר מישהו מהרשימה, באקראי ובלי ויכוחים. מורה משתמשת בו כדי לבחור מי עונה, מי קורא ומי תורן. מדריך בוחר מי מתחיל במשחק. במשפחה מגרילים מי בוחר את הסרט, ובעבודה מי מביא עוגה ביום שישי.

    איך משתמשים

    מדביקים את רשימת השמות, שם בכל שורה, ולוחצים "לסובב". השם שעלה בגורל מוצג בגדול. כברירת מחדל הוא יוצא מהגלגל, כך שבסיבוב הבא עולה מישהו אחר, עד שכולם עלו. "להחזיר את כולם" מחזיר את הרשימה המלאה. רוצים שהשמות יישארו? מבטלים את הסימון "להוציא מהגלגל את מי שעלה בגורל".

    רשימת התוצאות

    מתחת לגלגל נשמר הסדר: מי עלה ראשון, שני ושלישי. כך אפשר לקבוע סדר הצגות, סדר תורות או סדר ישיבה, ולשלוח את הרשימה בווטסאפ. הרשימה נשמרת במכשיר גם אם סוגרים את הדף, ולכן אפשר להמשיך באותה כיתה גם מחר.

    למקרן ולכיתה

    "מסך מלא" מציג רק את הגלגל, בגדול. אפשר לשלוח את הגלגל בקישור למורה אחרת או להורים, והם יקבלו את אותה רשימה. השמות נשארים במכשיר ולא נשלחים לשום מקום. צריכים כמה זוכים בבת אחת? יש הגרלת שמות. רוצים גלגל עם אפשרויות אחרות? יש גלגל המזל. ולמורים יש גם כיתה משחקת.

    שאלות ותשובות

    איך מכניסים את השמות של הכיתה?

    מדביקים את הרשימה בתיבה, שם בכל שורה. אפשר להעתיק אותה מוורד, מאקסל או מקבוצת הווטסאפ.

    איך דואגים שכל תלמיד יעלה רק פעם אחת?

    משאירים מסומן "להוציא מהגלגל את מי שעלה בגורל". אחרי כל סיבוב השם יוצא, עד שכולם עלו.

    השמות נשמרים אצלכם?

    לא. הרשימה נשמרת רק במכשיר שלכם, ולא נשלחת לשום מקום.

    אפשר להציג את הגלגל על מקרן?

    כן. "מסך מלא" מציג רק את הגלגל ואת מי שעלה בגורל, בגדול.

    הבחירה הוגנת?

    כן. לכל שם יש אותו סיכוי בכל סיבוב, והבחירה אקראית לגמרי.

    זה בחינם?

    כן. בחינם, בלי הרשמה ובלי פרסומות.
