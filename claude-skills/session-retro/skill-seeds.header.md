# Skill Pipeline - בנק זרעים ורעיונות

Every skill idea lives here until it is built or declined - one place shared by
`session-retro`, `skill-scout` and `skill-forge`. Newest first; keep entries as history.

**Statuses:** 🌱 זרע (taking shape) · 🌿 בשל (ripe - build it) · 💡 הוצע (skill-scout offered it) ·
🔨 בבנייה (brief in `briefs/`, build session proposed) · ✅ נבנה (`skill-name`) · ⛔ נדחה (reason - never offer again)

**Ripe when:** worked end-to-end at least once, OR seen in 2+ sessions, OR the project ended.
**Last day review:** -

Copy this template for each new entry (newest first):

```
## <name> - 🌱 זרע
- **פרויקט:** ...
- **נפתח:** YYYY-MM-DD | **עודכן:** YYYY-MM-DD | **שיחות:** 1
- **מה עושה:** one line
- **מה כבר ידוע:** steps / commands / tools that worked
- **מה עוד חסר:** untested parts, open questions
- **ציון:** R? T? E? | מאמץ S/M/L        (when scored)
- **בריף:** briefs/<name>.md            (when 🔨)
```
