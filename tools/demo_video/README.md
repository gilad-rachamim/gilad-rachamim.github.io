# סרטוני הדמיה ופרוספקטים לכלים (14.11.2026)

גילעד: "סרטוני הדמיה באתר לכל כלי שמסביר בתמונות ומוזיקה איך משתמשים... ומה מיוחד לשותפים",
"ודף פרוספקט מעוצב לכל כלי... שאפשר לשתף בו ובסרטון חברים מעבר לאתר".

## מה יוצא מכל מפרט
`specs/<tool>.json` (ה-id = השדה `"tool"` במטא של דף הכלי) ←
`python -I tools/demo_video/render.py tools/demo_video/specs/<tool>.json` ← לתוך `assets/demo/`:

| קובץ | מה |
|---|---|
| `<tool>.mp4` | סרטון אנכי 720x1280, ~45 שניות, מוזיקה מסונתזת (`music.py`, בלי זכויות יוצרים) |
| `<tool>.jpg` | תמונת פתיחה |
| `<tool>-post.png` | פרוספקט 1080x1350 לווטסאפ/פייסבוק/אינסטגרם, עם QR לדף |
| `<tool>-status.png` | פרוספקט 1080x1920 לסטטוס |

אחר כך `python build.py`: כל דף שיש לו `assets/demo/<tool>.mp4` מקבל לבד, מתחת ל-header, בלוק
"🎬 <name>" עם הסרטון, כפתור "לשלוח את הסרטון לחבר" (בטלפון נשלח הקובץ עצמו), הורדה, והפרוספקט.
מקום אחר בדף: לשים `<!--demo-->`. ה-VideoObject לגוגל נכנס לבד. אירועי Analytics: `demo_play`, `demo_share`, `demo_download`.

## סוגי סצנות (engine.html)
`title` · `chat` (צ'אט טלגרם עם הודעות, סרטון וכפתורים) · `karaoke` · `steps` · `cards` (+`"cls":"gold"` לשותפים) · `nums` · `shot` (צילום מסך של הכלי בתוך טלפון, `img` + `scroll`) · `cta` · `html`.
טקסט בין כוכביות `*כך*` יוצא בזהב. `dur` = שניות. סדר מומלץ: מה זה ← איך זה נראה ← 3 צעדים ← מה כלול ← בחינם ← לשותפים ← לאן נכנסים.

## בדיקה לפני מסירה
- הפרוספקט: אין `WARN flyer ... overflows` בפלט.
- פריימים: `ffmpeg -i assets/demo/<tool>.mp4 -vf "fps=1/4,scale=270:-1,tile=5x3" grid.png` ולהסתכל.
- תמיד "שותפים במיזם" / "שותפות במיזם", אף פעם לא "שותפים" לבד (גילעד 14.11.2026: "אני רוצה שתמיד יהיה כתוב מיזם").
- המותג בסרטון ובפרוספקט: "מיזם הכלים של גילעד רחמים" (גילעד 14.11.2026: "שקוראים לי מיזם הכלים").
- עובדות רק מהקוד/הדף של הכלי (מכסות, מחירים, כפתורים). שירים בסרטון – רק "בוקר חדש" (נכתב לאתר), לא שירים מוגנים.
