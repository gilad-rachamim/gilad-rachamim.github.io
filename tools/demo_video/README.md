# סרטוני הדמיה ופרוספקטים לכלים (14.11.2026)

גילעד: "סרטוני הדמיה באתר לכל כלי שמסביר בתמונות ומוזיקה איך משתמשים... ומה מיוחד לשותפים",
"ודף פרוספקט מעוצב לכל כלי... שאפשר לשתף בו ובסרטון חברים מעבר לאתר".

## מה יוצא מכל מפרט
`specs/<tool>.json` (ה-id = השדה `"tool"` במטא של דף הכלי) ←
`python -I tools/demo_video/render.py tools/demo_video/specs/<tool>.json` ← לתוך `assets/demo/`:

| קובץ | מה |
|---|---|
| `<tool>.mp4` | סרטון אנכי 720x1280, ~45 שניות, מוזיקה מסונתזת (`music.py`, בלי זכויות יוצרים) |
| `<tool>.jpg` | תמונת פתיחה |
| `<tool>-post.png` | פרוספקט 1080x1350 לווטסאפ/פייסבוק/אינסטגרם, עם QR לדף |
| `<tool>-status.png` | פרוספקט 1080x1920 לסטטוס |

אחר כך `python build.py`: כל דף שיש לו `assets/demo/<tool>.mp4` מקבל לבד, מתחת ל-header, בלוק
"🎬 <name>" עם הסרטון, כפתור "לשלוח את הסרטון לחבר" (בטלפון נשלח הקובץ עצמו), הורדה, והפרוספקט.
מקום אחר בדף: לשים `<!--demo-->`. ה-VideoObject לגוגל נכנס לבד. אירועי Analytics: `demo_play`, `demo_share`, `demo_download`.

## סוגי סצנות (engine.html)
`title` · `chat` (צ'אט טלגרם עם הודעות, סרטון וכפתורים) · `karaoke` · `steps` · `cards` (+`"cls":"gold"` לשותפים) · `nums` · `shot` (צילום מסך של הכלי בתוך טלפון, `img` + `scroll`) · `cta` · `html`.
טקסט בין כוכביות `*כך*` יוצא בזהב. `dur` = שניות. סדר מומלץ: מה זה ← איך זה נראה ← 3 צעדים ← מה כלול ← בחינם ← לשותפים ← לאן נכנסים.

## בדיקה לפני מסירה
- הפרוספקט: אין `WARN flyer ... overflows` בפלט.
- פריימים: `ffmpeg -i assets/demo/<tool>.mp4 -vf "fps=1/4,scale=270:-1,tile=5x3" grid.png` ולהסתכל.
- תמיד "שותפים במיזם" / "שותפות במיזם", אף פעם לא "שותפים" לבד (גילעד 14.11.2026: "אני רוצה שתמיד יהיה כתוב מיזם").
- המותג בסרטון ובפרוספקט: "מיזם הכלים של גילעד רחמים" (גילעד 14.11.2026: "שקוראים לי מיזם הכלים").
- עובדות רק מהקוד/הדף של הכלי (מכסות, מחירים, כפתורים). שירים בסרטון – רק "בוקר חדש" (נכתב לאתר), לא שירים מוגנים.

## כל הכלים, אוטומטית ובענן (15.11.2026)
גילעד: "תריץ על כל הכלים באתר... הכל באהבה ממיזם הכלים של גילעד רחמים מיזם חינמי כדי להנגיש... לא הכל זה כסף!!"
- `autospec.py`: מפרט לכל כלי ב-`kelim/tools.json` (בלי דפי מרכז) מתוך הדף עצמו: H1, כותרת השיתוף, צעדים מ"איך..." רק אם הם
  נשמעים כמו הוראה ("בוחרים", "לוחצים"...; אחרת בלי סצנת צעדים), "מה כלול" מכותרות ה-h3, פס החסד הבנוי (בחינם / ללא הגבלה),
  וצילום אמיתי של `.tool` ברוחב טלפון. סצנת זהב קבועה "💛 באהבה ממיזם הכלים · מיזם חינמי, כדי להנגיש": לשתף, לעזור בלי כסף
  (`/kelim/#truma`), שותפות במיזם. כלים רגישים (נפש, אזכרה, אבלות) – מוזיקה רגועה ובלי שום בקשת כסף.
- מפרט ביד ב-`specs/<tool>.json` תמיד גובר. מפרט אוטומטי ב-`specs/auto/` (540x960, crf 29, 24fps, רק פרוספקט פוסט).
- הרינדור בענן: `.github/workflows/demo-videos.yml` (Run workflow; 20 מכונות; `--changed` לפי hash של המפרט והמנוע).
- הדף: `kelim.js` קורא `assets/demo/index.json` ומכניס את הבלוק (אחרי הכלי, לפני ההסברים) כשהדף עוד לא נבנה איתו.
  `build.py` מכניס את אותו בלוק סטטית בבנייה הבאה. שורת "לא הכול זה כסף" בשניהם.

## סרטוני תדמית למיזם כולו (15.11.2026)
גילעד: "שתיים שלוש סרטוני תדמית לכל האתר והתוסף והאפליקציה... כולל הבוט בטלגרם ובווצאפ".
- מפרטים: `specs/promo/` (`"promo": true`): promo_atar (האתר), promo_tosaf (התוסף + האפליקציה בקרוב), promo_botim (הבוטים).
- יוצא ל-`assets/promo/`: `<id>.mp4` אנכי 1080x1920 (המנוע ב-720x1280 בצפיפות x1.5), `<id>-wide.mp4` רחב 1920x1080
  (האנכי באמצע + רקע מטושטש + צד ימין "מה זה" וצד שמאל QR, לפי `"wide"` במפרט), ו-`<id>.jpg`.
- רינדור בענן: Actions -> promo-videos -> Run workflow. תצוגה מקדימה במחשב (קלה): `render.py specs/promo --fps 1` -> `assets/promo/preview/`.
- צילומים: `promo_shots.py` (דפים חיים ברוחב טלפון) + צילומי החנות של התוסף והאפליקציה מהתיקיות בשולחן העבודה, ב-`shots/promo/`.
- סצנות חדשות: `montage` (רצף צילומים, `frame: phone|laptop`, items = [img, כיתוב, תת-כיתוב, גלילה]), `grid` (רשת תחומים 4 בשורה),
  `chat` עם `"wa": true` (ווטסאפ ירוק), `badge`/`title` מעל הצ'אט, והודעה קולית `{"voice": "1:05"}`.
- שם בוט בטקסט עברי: לעטוף ב-U+2066…U+2069, אחרת ה-@ קופץ לסוף.
- תיקון 15.11: הגופן של המנוע הצביע ל-`assets/Assistant-wght.woff` שלא קיים (הנכון: `assets/fonts/`).
